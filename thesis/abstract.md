# 摘要

个人知识管理工具普遍依赖用户手工整理笔记，沉淀成本高、检索体验差，难以支撑"随手记录、自动成库"的知识工作流。大语言模型与检索增强生成技术的发展，为个人知识的自动化沉淀与问答提供了新的技术可能，但现有方案多以云端服务为主，存在隐私暴露与成本不可控的问题。针对上述问题，本文设计并实现了基于大语言模型的多源知识采集与知识图谱问答系统 KnowSeq Agent，采用"采集层—编译层—大脑层—交互层"四层架构，全程本地化部署。采集层实现会议音频本地转写、系统声音直采、剪贴板监控、文件监听、网页抓取、飞书导入与手动导入七种入库通道，统一汇聚至只追加、不可变的素材库；编译层将开源流程移植适配为九步编译流水线，经质量闭环产出决策、教训、概念、关联、疑问五类结构化知识条目，并具备限流暂停、重试与双条件缓存能力；大脑层基于 LightRAG 封装同步门面，实现知识条目的增量幂等索引与本地三元存储，提供语义检索、带引用问答与图谱导出；交互层基于 FastAPI 与 React 实现七页控制台，以 sigma.js 结合 ForceAtlas2 与 Louvain 实现大规模图谱渲染，并通过 Tauri 桌面壳完成 Windows 集成。系统按五个里程碑完成开发与验收，23 条功能用例全部通过；端到端演示中 4 份种子素材经编译产出 11 条知识条目，图谱增至 1135 节点、2331 关系；开展 LightRAG 五种检索模式对比实验，完成 15 组实跑实测，结果表明 naive 模式在中小规模语料下时延最低，mix 模式综合表现最均衡，系统默认采用 hybrid 模式。本文验证了"大语言模型＋轻量级知识图谱＋本地部署"技术路线在个人知识管理场景下的可行性，为同类系统的构建提供了可复现的工程参考。

**关键词**：大语言模型；知识图谱；检索增强生成；多源信息采集；本地部署

# Abstract

Existing personal knowledge management tools rely heavily on manual note-taking, which is costly to maintain and unsuitable for a "capture-and-forget" knowledge workflow. The development of large language models (LLMs) and retrieval-augmented generation (RAG) opens new possibilities for automated personal knowledge distillation and question answering. However, most existing solutions are cloud-based and suffer from privacy leakage and uncontrollable costs. To address these issues, this thesis designs and implements KnowSeq Agent, a multi-source knowledge acquisition and knowledge-graph question answering system based on LLMs, following a four-layer architecture of acquisition, compilation, brain, and interaction, fully deployed locally. The acquisition layer provides seven ingestion channels, including local meeting transcription, system-audio loopback capture, clipboard monitoring, file watching, web-page extraction, Feishu import, and manual import, all unified into an append-only immutable inbox. The compilation layer adapts an open-source workflow into a nine-step pipeline that produces five categories of structured knowledge entries through a quality loop, with rate-limit pausing, retry, and dual-condition caching. The brain layer wraps LightRAG into a synchronous facade, achieving incremental idempotent indexing and local triple storage, and provides semantic retrieval, cited question answering, and graph export. The interaction layer implements a seven-page console based on FastAPI and React, renders large-scale graphs with sigma.js combined with ForceAtlas2 and Louvain, and integrates with Windows through a Tauri desktop shell. The system was developed and accepted over five milestones, with all 23 functional test cases passed. In the end-to-end demonstration, 4 seed materials produced 11 knowledge entries, and the graph grew to 1,135 nodes and 2,331 edges. A comparative experiment on the five retrieval modes of LightRAG was conducted with 15 measured runs, showing that the naive mode achieves the lowest latency on small-to-medium corpora while the mix mode is the most balanced overall, and the system adopts hybrid as its default mode. This thesis verifies the feasibility of the "LLM + lightweight knowledge graph + local deployment" approach in personal knowledge management and provides a reproducible engineering reference for similar systems.

**Key words**: large language model; knowledge graph; retrieval-augmented generation; multi-source information acquisition; local deployment

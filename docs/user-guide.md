# KnowSeq Agent 使用指南

面向使用者的完整说明：系统是什么、如何安装启动、每个功能怎么用。

> 开发协作文档（架构 / 需求 / 任务 / ADR）见 [README.md](../README.md) 文档导航。

## 1. 系统概览

KnowSeq Agent 是**本地轻量运行**的个人知识管理 Agent，核心是一条自动化流水线：

```
采集（六源 + 手动导入） → inbox/ 素材 → LLM 编译提炼 → knowledge/ 知识条目（五类）
       → LightRAG 大脑索引（向量 + 图谱） → 带引用溯源的问答 / 知识图谱可视化
```

- 全部数据存放在项目目录内（`inbox/`、`knowledge/`、`.knowseq/`），不上传本地文件本体；
- 仅编译/问答环节调用**云端 LLM**（默认火山方舟 deepseek-v4-flash，凭据在 `.env`）；
- 一个 Python 后端进程承载全部服务（端口 8765），带系统托盘常驻。

## 2. 环境要求与安装

### 2.1 必需

- Windows 10/11（托盘、右键菜单、系统声音采集均为 Windows 能力）
- Python 3.11+，创建虚拟环境并安装依赖：

```bat
cd /d <项目根>
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

- `.env` 配置（从模板复制后填写）：

```bat
copy .env.example .env
```

| 变量 | 必填 | 用途 |
|---|---|---|
| `LLM_API_KEY` | 是 | 编译层调用云端 LLM 提炼知识（配合 config.yaml `compile.llm.base_url/model`） |
| `LLM_BASE_URL` / `LLM_MODEL` | 否 | 不填则使用 config.yaml 中的值 |
| `FEISHU_APP_ID` 等 | 否 | 飞书云文档导入（REQ-106），不用飞书可不填 |

- Embedding 模型：本地模式使用 `models/embed/bge-small-zh-v1.5`（已随项目目录放置，无需联网下载）。

### 2.2 可选组件（缺失时对应源降级为「错误」，不影响其他功能）

| 组件 | 用途 | 说明 |
|---|---|---|
| VibeASR.cpp 引擎 | 会议音频转写 | 外部 C++ 可执行件 + gguf 模型（`tools/vibeasr/`、`models/vibeasr/`），构建说明见 [docs/vibeasr-usage.md](vibeasr-usage.md) |
| 桌面壳（Tauri） | 主窗/悬浮控件/壳托盘 | 见第 4.3 节，纯浏览器使用可不装 |
| Rust 工具链 | 仅构建壳需要 | rustup + MSVC Build Tools |

## 3. 启动与停止

### 3.1 启动后端（推荐日常方式）

```bat
cd /d <项目根>
.venv\Scripts\python run.py
```

启动后（约 10~30 秒）：

- 任务栏通知区出现 **pystray 托盘**（蓝底图标，悬浮名「KnowSeq Agent」）；
- 浏览器打开 **控制台**：`http://127.0.0.1:8765`（也可托盘右键「打开控制台」）；
- 按设置页中各源开关（`sources.*.enabled`）自动开始采集。

> 后台常驻：`run.py` 启动即带托盘，控制台窗口可最小化；`web.auto_start: true` 时启动即恢复采集。

### 3.2 开机自启（可选）

控制台 → **设置页 → 开机自启** 开关打开后：

- 写入 HKCU Run 键 `KnowSeq`（venv pythonw 静默拉起 `run.py`，无黑窗）；
- 关闭开关即删键、不再自启；
- 自启对象是**后端含托盘**（不含桌面壳）。

### 3.3 停止

- **停采集**：托盘左键单击「切换采集」，或控制台采集页「结束采集」；
- **退出程序**：托盘右键「退出」（会先停全部采集源再退出）。

### 3.4 桌面壳（可选，Tauri）

开发运行：

```bat
cd shell
npm install
npm run tauri dev
```

正式构建（NSIS/MSI 安装包，`shell/src-tauri/target/release/bundle/`）：

```bat
cd shell
npm run tauri build
```

壳的行为：

- **主窗**加载控制台 `http://127.0.0.1:8765`；后端未启动时显示内置提示页（非白屏）；
- **关窗 ≠ 退出**：点 X 仅隐藏主窗，采集与后端不受影响；二次启动唤出已有实例（单实例）；
- **壳托盘**菜单：「显示主窗」「悬浮控件」开关、「退出壳」；
- **悬浮控件**：透明置顶小窗（开始/结束采集两个按钮 + 状态色点），可拖拽、任务栏无图标；「结束」会停止系统声音采集并收尾转写最后一段。

## 4. 控制台功能页

左侧导航 7 页，侧栏底部有**采集/编译/大脑全局状态轨**。

### 4.1 问答

在输入框提问，系统基于大脑索引返回**带引用溯源**的回答：每条结论标注来源知识条目，点引用跳转对应条目。未做索引或刚入库未编译时回答质量受限——先完成「采集 → 编译 → 大脑索引」。

### 4.2 图谱

知识图谱可视化（实体节点 + 关系边），可拖拽布局、查看节点详情。图谱规模随大脑索引增长。

### 4.3 知识库

浏览/编辑/删除五类知识条目（编译产出）：

| 类别 | 目录 | 含义 |
|---|---|---|
| decisions | `knowledge/decisions/` | 决策、结论、方案选择 |
| lessons | `knowledge/lessons/` | 经验教训、踩坑记录 |
| concepts | `knowledge/concepts/` | 概念、技术要点、事实 |
| connections | `knowledge/connections/` | 人物/项目/事物间的关联 |
| queries | `knowledge/queries/` | 待跟进的开放问题 |

删除条目会同步清理大脑索引（保持一致）。

### 4.4 编译

- 队列状态（待处理/进行中/失败）与手动触发重编译；
- **人工复核**：LLM 判断为疑似重复/低质/需合并的条目在此裁决（通过/修改/驳回）；
- lint（语义校验）与去重预览工具。

### 4.5 素材

`inbox/` 原始素材列表：预览全文、标记（已处理/忽略）、查看来源与时间。素材是知识条目的溯源起点。

### 4.6 采集控制

三区：

1. **源开关卡片**：六个采集源逐个启停（开关同时持久化到设置，重启后按此恢复）；
2. **手动导入**：粘贴文本（带标题）或上传文件（md/txt 等）直接入 `inbox/manual/`；
3. **网页抓取 / 飞书导入**：输入 URL 抓取正文入库；输入飞书文档链接导入（需凭据）。

「结束采集」一键停止全部源（右键菜单的「立即结束采集」等同此操作）。

### 4.7 设置

分组表单对齐 config.yaml：Web 端口与自启、六源开关、监听目录、编译 LLM、大脑 Embedding/LLM、飞书凭据、**开机自启**、**右键菜单安装/卸载**。敏感项（API Key）只写不回读；端口/LLM 类改动需重启后端生效。

## 5. 六个采集源详解

| 源 | 触发方式 | 产出 | 备注 |
|---|---|---|---|
| **会议转写** meeting | 把音频文件（wav/mp3/m4a…）拖入项目 `drop/` 目录 | `inbox/meeting/` 转写稿 | 本地 VibeASR 转写；引擎未就绪该源置「错误」 |
| **系统声音** system_audio | 开启后持续监听默认输出设备（loopback） | `inbox/meeting/` 定长分段转写稿（默认 300s/段） | 可配 `include_mic` 混入麦克风；开会时开着即可，结束自动收尾最后一段；**无语音播放时段为低电平噪声，可能出现转写失败/幻觉（已观察记录）** |
| **剪贴板** clipboard | 复制任意文本（≤50000 字） | `inbox/clipboard/` | 2 秒轮询去重 |
| **文件** file | 监听目录内新增文本文件 | `inbox/file/` | 目录在设置页「监听目录」配置，或对文件夹右键「纳入 KnowSeq 采集」 |
| **网页** web | 采集控制页输入 URL（按需） | `inbox/web/` 正文 | readability 抽取正文 |
| **飞书** feishu | 采集控制页输入云文档链接（按需） | `inbox/feishu/` | 需 `.env` 凭据 |

入库后即进入编译流水线（`compile.auto: true` 时约 30 秒内自动入队），无需手工干预。

## 6. Windows 集成

- **文件夹右键菜单**（设置页安装/卸载，写 HKCU 无需管理员）：
  - 「纳入 KnowSeq 采集」：把该文件夹加入文件源监听并持久化；
  - 「立即结束采集」：一键停止全部采集源。
- **开机自启**：设置页开关（见 3.2）。
- **双托盘职责分离**：pystray 托管后端/采集（「退出」会停后端）；壳托盘只管窗口显隐（「退出壳」不影响后端）。

## 7. 配置速查（config.yaml）

| 配置 | 默认 | 说明 |
|---|---|---|
| `web.port` | 8765 | 控制台/API 端口（改后重启生效） |
| `web.auto_start` | true | 后端启动时自动开始采集 |
| `app.autostart` | false | 开机自启（与设置页开关联动） |
| `compile.auto` | true | 素材入库后自动编译 |
| `compile.llm.*` | 方舟 deepseek | 编译 LLM（Key 在 `.env`） |
| `compile.dedup.threshold` | 0.68 | 语义去重阈值 |
| `brain.embedding.mode` | local | 本地 bge-small-zh-v1.5 |
| `sources.system_audio.segment_seconds` | 300 | 系统声音分段时长 |
| `sources.file.dirs` | [] | 文件监听目录列表 |

## 8. 从零跑一遍（推荐首次体验路径）

1. 启动后端（3.1），浏览器开控制台；
2. 采集控制页 → 手动导入粘贴一段笔记，或复制几段文本让剪贴板源自动入库；
3. 素材页确认新素材 → 编译页看队列跑完（走真实 LLM，单条数十秒）；
4. 知识库页检查五类条目（如有复核项在编译页裁决）；
5. 大脑页确认索引就绪（或采集控制页触发索引）→ 问答页提问验证引用；
6. 图谱页看知识图谱。

**演示模式**（一键注入种子数据 + 预设问答清单 + 可清理，详见 [scripts/demo/README.md](../scripts/demo/README.md)）：

```bat
.venv\Scripts\python scripts\demo\run_demo.py      # 跑通全链路演示
.venv\Scripts\python scripts\demo\cleanup_demo.py  # 清理演示产物（需后端在线）
```

## 9. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 打开 8765 无响应 | 后端未启动或端口被占用；改 `web.port` 或释放端口后重启 |
| 编译一直失败 | `.env` 未填 `LLM_API_KEY` 或 base_url/model 不可达；设置页检查编译 LLM 配置 |
| 会议转写源「错误」 | VibeASR 引擎/模型未就绪（可选组件）；见 docs/vibeasr-usage.md |
| 系统声音转写偶发失败/英文幻觉 | 低电平（无语音播放）段的已知现象，失败段自动跳过不影响其他段；开会正常使用不受影响 |
| 状态轨「失败 N」常驻 | 编译队列中文件已被删除的历史死任务残留（重试耗尽标记失败），不影响新素材编译 |
| 问答引用不到新内容 | 素材需完成「编译 → 大脑索引」两步后才可被引用；采集控制页可手动触发索引 |
| 改了设置不生效 | 端口/LLM/Embedding 类配置需重启后端 |
| 壳窗口空白 | 后端未启动；先 `python run.py`，壳会自动探测并进入控制台 |

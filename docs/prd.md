# 需求规格（PRD）

## 1. 项目概述

本地轻量运行的 AI 知识管理 Agent：自动无感采集多源知识 → 云端 LLM 提炼为结构化知识 → LightRAG 构建向量检索 + 知识图谱大脑 → 带引用溯源的问答与图谱可视化。目标用户为个人/小型团队的日常办公知识积累。

## 2. 功能需求

### 2.1 采集层（FR-001 ~ FR-006）

| ID | 需求描述 | 验收标准 |
|---|---|---|
| FR-001 | 会议音频采集：会议/通话录音文件本地转写（VibeVoice-ASR-BitNet，CPU 实时，输出结构化文本；ADR-014） | 转写结果写入本地 inbox/；数据不出本机；可开关 |
| FR-002 | 对话采集（微信/企微）：监控剪贴板，用户复制的文本自动进入采集 | 复制的文本可被识别并写入 inbox/（标注来源=剪贴板） |
| FR-003 | 对话采集（飞书）：通过飞书开放平台机器人事件订阅接收消息，云文档可导出导入 | 群聊/单聊消息经机器人事件自动写入 inbox/；云文档可手动/定时导入 |
| FR-004 | 文件采集：监听指定文件夹新增/修改的文档（pdf/docx/md/txt 等），支持拖拽/批量导入 | 新增文件自动进入 inbox/ 或解析队列；可配置监听目录 |
| FR-005 | 网页采集：输入 URL 自动抓取并抽取正文 | 正文清洗后写入 inbox/，附带来源 URL |
| FR-006 | 手动导入：粘贴文本或拖入文件即刻入库 | 手动入口可用，导入后可查看 |

### 2.2 编译层（FR-010 ~ FR-011）

| ID | 需求描述 | 验收标准 |
|---|---|---|
| FR-010 | 增量提炼：对 inbox/ 新增素材，用云端 LLM 提炼为结构化知识条目（决策/教训/概念/连接），复用 memory-compiler 编译思想 | 每条产出带来源引用；幂等（重复执行不重复产出） |
| FR-011 | 触发方式：自动（新素材到达即触发/定时）+ 手动（界面按钮） | 两种方式均可触发，可配置 |

### 2.3 大脑层（FR-020 ~ FR-022）

| ID | 需求描述 | 验收标准 |
|---|---|---|
| FR-020 | 向量化索引：提炼后的知识条目建立向量索引 | 支持语义检索 |
| FR-021 | 知识图谱：自动抽取实体与关系，构建并可视化知识图谱 | 图谱可导出/可浏览 |
| FR-022 | 引用溯源：回答可回溯到具体来源素材 | 每条回答带来源引用 |

### 2.4 查询与图谱（FR-030 ~ FR-031）

| ID | 需求描述 | 验收标准 |
|---|---|---|
| FR-030 | 问答：自然语言提问，基于知识库回答并带引用 | 回答引用可见、可点击跳转来源 |
| FR-031 | 图谱浏览：交互式知识图谱页面，支持缩放/点击节点 | 图谱页可用 |

### 2.5 管理（FR-040 ~ FR-042）

| ID | 需求描述 | 验收标准 |
|---|---|---|
| FR-040 | 素材管理：查看 inbox/ 原始素材列表与状态（待提炼/已提炼） | 可查看、可标记 |
| FR-041 | 知识管理：查看/编辑提炼后的知识条目 | 可浏览，可删除（删除需确认） |
| FR-042 | 设置：LLM API（厂商/Key/模型）、embedding、监听目录、采集开关、触发频率 | 配置持久化，重启生效 |

### 2.6 Windows 集成（FR-050 ~ FR-052）

| ID | 需求描述 | 验收标准 |
|---|---|---|
| FR-050 | 托盘图标：左键单击开始/结束采集；右键菜单（开始/结束采集、打开控制台、退出） | 托盘常驻，左键可开关 |
| FR-051 | 资源管理器右键菜单：在文件夹上右键可"纳入知识采集"；提供"立即结束采集" | 注册表注入，点击生效 |
| FR-052 | 全局快捷键（可选）：一键开关采集 | 快捷键生效 |

## 3. 范围边界（明确不做 / 延后）

- 团队协作、账号与权限体系 —— **不做**（个人工具）
- 完全离线推理 —— **不做**（采用云端 LLM API，采集本身本地化）
- 移动端 —— **延后**
- 竞赛申报材料 —— **延后**（文档体系稳定后再补）
- 多模态（图像内容理解、视频）—— **延后**
- 微信/企微自动读聊天记录 —— **不可行**（无官方 API），采用剪贴板监控的现实路径

## 4. 非功能需求

| ID | 需求 | 说明 |
|---|---|---|
| NFR-001 | 数据本地优先 | 除 LLM/embedding API 调用外，所有数据存储与处理在本机 |
| NFR-002 | 隐私 | LLM API Key 仅本地配置，不落库外传、不写入日志 |
| NFR-003 | 轻量 | 尽量轻依赖，避免重型运行时；可后台常驻 |
| NFR-004 | 增量 | 编译/索引只处理新增，不重复全量 |
| NFR-005 | 可审计 | 回答与知识条目可溯源到原始素材 |
| NFR-006 | 可恢复 | 采集素材只追加不修改，支持重跑提炼流水线 |

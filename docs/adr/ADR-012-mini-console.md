# ADR-012 M1 提前引入极简本地控制台

## 背景

M1 需要"手动导入（粘贴文本/上传文件）""采集状态查看""一键开关"等人手入口。原规划把完整 Web 控制台放 M4，但 M1 的手动导入与状态查看需要一个交互载体。

## 决策

- M1 提前引入 **FastAPI 本地服务 + 极简单页**（`app/web/server.py` + `app/web/static/`），仅本机监听。
- 范围限定为管理类能力：采集状态、一键开关、手动导入表单、素材列表、设置（飞书凭据/监听目录/各源开关）。
- **完整交互层**（问答页、图谱页、知识管理、完整设置 UI）仍属 M4（ADR-010），M1 的 FastAPI 为其铺路不重复建设。

## 备选方案与理由

- **纯无 UI（热文件夹 + 命令行）**：最轻，但"粘贴文本导入"与"状态查看"体验差 → 不选（用户已确认选极简控制台）。
- **直接上完整控制台（拉 M4）**：超出 M1 范围 → 只做极简子集。

## 后果

- FastAPI/uvicorn 提前进入依赖；M1 交付物包含本地服务启动。
- M4 可复用本服务的 API 与静态资源结构，无需推翻。

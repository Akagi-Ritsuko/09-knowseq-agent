# ADR-001 技术栈与运行形态

## 背景

需要一个**本地运行、尽量轻量**的独立 Agent/项目（不依赖 Trae），供竞赛与个人使用。采集全部本地化，但 LLM 提炼与向量化采用**云端 API**（DeepSeek / Qwen / GLM，OpenAI 兼容），不做完全离线。

## 决策

- 后端：Python + FastAPI（本地服务 + API）。
- 模型：云端 OpenAI 兼容 LLM API + 云端 embedding API。
- 运行形态：本地常驻进程（系统托盘图标）+ 浏览器访问本地 Web。
- 采集本地化：屏幕/音频（本地 OCR/Whisper）、剪贴板、文件等一律不出本机；仅 LLM/embedding 请求出网。

## 备选方案与理由

- **本地模型（Ollama 等）**：可完全离线，但小模型提炼质量弱、需较重运行时，且竞赛演示不要求离线 → 不选。
- **完全自研全栈**：可控但工程量大 → 本决策采用"现成组件 + 轻量自研"组合（见后续 ADR）。

## 后果

- 需要联网调用 LLM/embedding；API Key 本地配置（NFR-002）。
- 采集数据本地存储，符合数据本地优先（NFR-001）。

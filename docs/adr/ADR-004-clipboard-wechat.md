# ADR-004 微信/企微对话采集

## 背景

对话是重要知识源。微信/企微**没有官方开放接口**，无法程序化自动读取聊天记录。

## 决策

- 微信/企微对话采用**剪贴板监控**：用户复制文本时自动捕获并写入 `inbox/`（来源=剪贴板）。
- 第三方导出工具（如 WeChatMsg/留痕）导出的聊天文件可走"文件导入"通道（ADR-006）作为补充。

## 备选方案与理由

- **hook/注入读取聊天记录**：违反平台规则、不稳定 → 不选。
- **手动导出工具**：被动、需人工 → 仅作补充通道。
- 剪贴板监控是无感、合规、稳定的现实最优路径。

## 后果

- 仅能采集用户主动复制的文本（被动但无感）；需在 PRD/README 明确该边界，避免演示预期偏差。
- 实现为轻量自研（轮询/钩子），纳入采集开关统一控制。

# ADR-005 飞书采集

## 背景

用户要求对话类知识源除微信/企微外**也支持飞书**。飞书有官方开放平台，可做比剪贴板更深的自动化集成。

## 决策

- 采用**飞书开放平台自建应用**做深集成，两条通道：
  1. **消息事件订阅**：机器人接收群聊/单聊消息事件，采用 **WebSocket 长连接模式**（无需公网回调地址，适合本地程序），消息写入 `inbox/`（来源=飞书，含会话标识）。
  2. **云文档导出导入**：通过开放文档 API 导出 docx/正文，走文件/素材导入通道。
- 需要用户提供飞书自建应用凭证（App ID/Secret）并开通机器人与相应权限。

## 备选方案与理由

- **仅剪贴板监控**：被动、丢失上下文（会话/发送者）→ 不满足"飞书也支持"。
- **Webhook 回调模式**：需公网回调地址，本地程序不可行 → 选长连接模式。

## 后果

- 需要飞书开放平台配置（自建应用、机器人权限、事件订阅），M1 需在 README/设置页给出配置指引。
- 飞书消息为主动、无感采集，体验优于剪贴板。

# ADR-011 Windows 集成

## 背景

需要"一键开始/结束采集"的轻量入口。用户要求支持 Windows 左键/右键快速开关。

## 决策

- **系统托盘图标（pystray）为主**：
  - 左键单击 = 开始/结束采集（一键切换全部采集源）。
  - 右键菜单 = 开始采集 / 结束采集 / 打开控制台 / 退出。
  - 开机自启：注册表 `Run` 项或启动文件夹快捷方式（M5）。
- **资源管理器右键菜单（注册表注入，HKCU 无需管理员）为辅**：
  - 在文件夹上右键 → "纳入知识采集"（把该目录加入文件监听，ADR-006）。
  - 提供"立即结束采集"入口。
- **全局快捷键（可选）**：一键开关采集（M5 评估）。

## 备选方案与理由

- **仅命令行**：不够"无感" → 不选。
- **仅右键菜单**：在资源管理器里开关采集不方便 → 以托盘左键为主、右键菜单做"纳入采集"。

## 后果

- 托盘依赖 pystray + Pillow；右键菜单需写注册表（卸载时清理）。
- 进程需常驻；托盘/注册表均由采集开关统一控制。

## 关联

- 关联里程碑：M1（托盘雏形）/ M5（右键菜单、快捷键、自启）
- 关联任务：T-008、T-012
- 相关 ADR：ADR-006（文件采集）
- 需求：FR-050、FR-051、FR-052

# ADR-006 文件采集

## 背景

需要把既有文档（pdf/docx/md/txt 等）批量纳入知识库，并持续监听新文件。

## 决策

- 采用 **watchdog** 监听用户配置的目录：新增/修改的文件进入采集解析队列。
- 提供**拖拽/批量导入**入口（前端页面 + 文件夹右键"纳入知识采集"，见 ADR-011）。
- 支持格式：Markdown、TXT、DOCX、PDF 等（解析能力按需扩展）。

## 备选方案与理由

- **全量扫描 + 定时轮询**：简单但重复、耗资源 → 用 watchdog 事件驱动 + 增量。
- **仅手动上传**：无感度不足 → 增加目录监听。

## 后果

- 需要解析多格式文档（PDF/DOCX 解析库），M1 先支持常用格式。
- 文件监听纳入采集开关统一控制（NFR-003 轻量）。

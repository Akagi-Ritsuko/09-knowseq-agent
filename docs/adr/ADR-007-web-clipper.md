# ADR-007 网页采集

## 背景

需要把网页/在线文章纳入知识库。

## 决策

- 采用 **URL 抓取 + 正文抽取**：输入 URL → 抓取 HTML → 抽取正文（可借助 readability 类库）→ 写入 `inbox/`（来源=URL）。
- 浏览器**剪藏扩展列为后续可选**（M5 或延后），M1 先实现 URL 抓取入口。

## 备选方案与理由

- **浏览器扩展剪藏**：体验好但需多端维护（Chrome/Edge 扩展）→ 延后。
- **直接存整页 HTML**：噪音大、占空间 → 抽取正文。

## 后果

- 依赖网络可达性；需处理反爬/动态页面（按需降级为"仅保存链接"）。
- URL 作为溯源标识保留。
